# Crear y subir un proyecto Laravel a GitHub

## 1. Inicializar Git en el proyecto

``` bash
cd ruta/a/tu/proyecto
git init
```

------------------------------------------------------------------------

## 2. Revisar el archivo .gitignore

Asegúrate de que NO se suben:

-   /vendor
-   /node_modules
-   .env

Laravel normalmente ya incluye un `.gitignore` correcto.

------------------------------------------------------------------------

## 3. Primer commit

``` bash
git add .
git commit -m "Primer commit proyecto Laravel"
```

------------------------------------------------------------------------

## 4. Crear repositorio en GitHub

1.  Ir a GitHub
2.  Pulsar "New repository"
3.  Introducir nombre

NO marcar: - Add README - Add .gitignore - Add license

------------------------------------------------------------------------

## 5. Conectar repositorio local con GitHub

``` bash
git remote add origin https://github.com/usuario/repositorio.git
git branch -M main
git push -u origin main
```

------------------------------------------------------------------------

## 6. Autenticación

GitHub requiere:

-   Token personal (PAT) o
-   SSH (recomendado)

------------------------------------------------------------------------

## 7. Uso del proyecto Laravel al clonarlo

``` bash
composer install
cp .env.example .env
php artisan key:generate
```

------------------------------------------------------------------------

## Notas importantes

-   Nunca subir `.env`
-   Compartir `.env.example`
